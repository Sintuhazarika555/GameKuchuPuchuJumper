##  Features

- **Minimalist Aesthetics:** Custom black-and-white visual identity with mobile-first UI layout.
- **Dynamic Score Tracking:** Real-time timer-based scoring integrated with Unity's `PlayerPrefs` for persistent local high scores.
- **Complete Game Loop:** Main scene menu, rules pre-game panel, pause/resume state management (`Time.timeScale`), game over conditions, and scene management.
- **Mobile Optimized:** Zero-latency audio import setup and native touch handling configured for Android builds.

---

##  Tech Stack & Tools

- **Engine:** Unity 6 (2D Pipeline)
- **Language:** C#
- **UI Framework:** TextMeshPro, Canvas UI Systems
- **Platform:** Android (APK / AAB)
